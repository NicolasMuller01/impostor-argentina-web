Correo de contacto

Para consultas generales, privacidad, publicidad o problemas del sitio, escribi a contacto@elimpostorargentina.com.

Si reportas un error, indica el dispositivo y navegador, la pantalla donde ocurrio y los pasos para reproducirlo. No envies nombres reales de otras personas, contraseñas ni informacion sensible.

Que tipo de mensajes sirven?

Errores y accesibilidad

Puedes avisar si una tarjeta se ve mal, si un boton no responde, si el texto tiene poco contraste o si una pantalla no funciona bien con teclado o lector de pantalla.

Datos para revisar

Si encuentras una afirmacion dudosa en Dato Random, copia el texto exacto y, si es posible, agrega una fuente confiable para que podamos revisarlo antes de modificarlo.

Tiempo de respuesta

Leemos los mensajes cuando podemos y priorizamos problemas que impidan jugar o afecten la privacidad. Un correo no garantiza una respuesta inmediata ni que toda sugerencia se incorpore, pero cada reporte concreto ayuda a decidir que mejorar.
