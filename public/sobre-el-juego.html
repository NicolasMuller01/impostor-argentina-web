Detras de la mesa

Sobre El Impostor Argentino

Creamos una version web liviana de un juego de deduccion social para que un grupo pueda empezar una partida en segundos, sin cuentas, sin turnos complicados y sin instalar nada.

Que queremos resolver

Muchos juegos de impostor funcionan bien cuando todos tienen una aplicacion, pero se vuelven lentos cuando hay que crear usuarios, esperar una sala o repartir materiales. En esta experiencia, una sola pantalla organiza la configuracion, entrega una consigna privada y guia la ronda hasta la votacion.

El juego esta pensado para reuniones, viajes, recreos y sobremesas. La tecnologia acompana la charla: no reemplaza las preguntas, las sospechas ni las reglas que cada grupo acuerda antes de comenzar.

Diseno de la experiencia

La interfaz prioriza botones grandes, textos breves y una tarjeta de revelacion que se puede usar con un toque. La informacion privada aparece solo en el turno correspondiente y la partida se reinicia desde el mismo lugar cuando el grupo quiere jugar otra vez.

Contenido local

Las categorias del modo Clasico toman referencias de comidas, lugares, musica, deportes y expresiones argentinas. El modo Dato Random suma temas de geografia, historia, naturaleza, cultura y ciencia para que cada partida tenga otra conversacion.

Como cuidamos el contenido

Las reglas, los textos de ayuda y las categorias se escriben para este proyecto. Los datos del modo Dato Random se revisan editorialmente y pueden corregirse cuando aparece una imprecision, cambia una referencia o una persona de la comunidad envia una observacion concreta. Un dato dentro de un juego no reemplaza una fuente educativa: para estudiar o verificar una afirmacion, consulten la fuente oficial correspondiente.

Tambien preferimos explicar como se juega antes que llenar la interfaz con elementos innecesarios. Si agregamos anuncios, deben quedar separados del contenido y no interrumpir una tarjeta privada ni una votacion.

Participar y mejorar

Los comentarios sobre accesibilidad, errores de redaccion y datos para revisar son bienvenidos. En la pagina de contacto explicamos como enviar una observacion util.
